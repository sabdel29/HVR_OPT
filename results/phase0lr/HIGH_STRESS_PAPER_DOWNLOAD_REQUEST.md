# High-stress SAC305 primary sources — institutional download request

**Phase 0L-R, Part 6.**

Phase 0L concluded that no suitable high-stress SAC305 data was retrievable and, being careful, did not conclude that none exists. Phase 0L-R re-searched on axes other than the word *creep* (multi-rate tensile, stress relaxation, Anand and Chaboche calibrations) and found a substantial, directly relevant corpus. Almost all of it is behind IEEE, ASME, Emerald or SSRN access that refuses scripted retrieval.

> **HIGH-STRESS CONSTITUTIVE CLOSURE IS ACCESS-GATED, NOT EVIDENCE-NEGATIVE.**

The user has institutional access. Each entry below names exactly what is needed from the PDF, so nothing has to be read twice.

One search result was retrieved and has already changed the phase result: **Yamin et al. 2025** (open access, Jurnal Teknologi) supplied a well-identified SAC305 Anand parameter set which re-admits the Anand family that Phase 0L had rejected. That is direct evidence that the remaining gap is retrieval, not existence.
