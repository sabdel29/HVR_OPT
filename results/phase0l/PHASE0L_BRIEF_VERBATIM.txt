HOWEVER, PHASE 0K-R UNCOVERED A MORE FUNDAMENTAL LIMITATION:

The SAC305 creep model was fitted to 19 measurements over approximately:

      T = 45, 80, 115, 150 C
      stress = 7.51–15.92 MPa

but damage-weighted solver stresses in the actual package are approximately:

      baseline ≈ 69 MPa
      45→125 C ≈ 91 MPa
      110→150 C ≈ 54 MPa

so the model is being evaluated roughly 3.4–7.2x above the fitted stress window during the
increments that contribute most strongly to the creep response.

This limitation exists not only in the proposed experiment profiles but in the normal
operating baseline.

There is also a potentially load-bearing semantic/implementation inconsistency:

The current report writes the creep law as approximately:

      eps_dot_cr = A(T) * sigma^n(T)

but Phase 0K-R interprets the driving quantity as:

      sigma_eq - sigma_y(T)

i.e. an overstress.

These are NOT automatically equivalent.

The exact solver implementation and the exact variable used when fitting the 19 experimental
data points must now be audited from first principles.
