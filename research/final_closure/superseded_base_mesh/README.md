# Superseded: local solder runs at the base-mesh critical joints

h_xy = 1.1 mm mesh. The nested mesh study showed that mesh fails the declared 2 %
tolerance on peak temperature, so the production lineage moved to the in-plane-refined
mesh (r21) and the local family was re-run at the r21 critical joints. Kept for
provenance only; not used by any current table, figure or claim.
