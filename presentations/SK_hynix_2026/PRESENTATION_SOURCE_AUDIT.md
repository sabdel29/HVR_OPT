# Presentation source audit

Generated by `make_docs.py`. Every quantitative value on a slide is loaded by `sources.py` from a frozen artifact at build time; none is typed into the deck.

## 1. How values reach a slide

```
frozen artifact  ->  sources.py  ->  figures.py / deck_content.py  ->  slide
```

`sources.py` fails loudly if an artifact is missing or a column is renamed, so a stale deck cannot be built silently.

## 4. Corrections made while building this deck

Three defects were found in draft figures and fixed before the deck was assembled. They are recorded here because each would have put a wrong claim on a slide.

1. **`p_rail` claimed “same via geometry”.** It is not the same. Z1's through-substrate path is 74 µm (substrate minus the embedded cell) and Z2's is 300 µm. The figure was redrawn with both substrates to a common scale and the claim removed.
2. **`p_rail` drew the wrong topology.** It showed the regulator inside the substrate for both cases. Per `scripts/phase0i/zarch.py`, Z2's chiplet sits BELOW the substrate and Z1's TSV sits BELOW the embedded cell. Redrawn.
3. **`p_tsvloss` claimed “identical via field, three orders of magnitude apart”.** The field is not identical, and Z1's ledger value is a small negative number (-0.00017 W) — a known small-signal artefact of adding an FV transition correction to a 74 µm bulk path. It is now reported as a bound, “below 0.2 mW”.

`h_sub`, the TSV path length, the rail currents, the die size, the stack height and the aspect ratios were hard-coded in those draft figures; all are now loaded by `sources.py` from the artifacts.
